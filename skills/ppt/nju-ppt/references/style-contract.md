# 南京大学固定风格：样式契约 v2

当前规则：用户已确认的银杏金底板＋清浅蓝辅助色。替代旧版 C 奋进蓝规则；以 `南京大学.pptx` 和新版11页审阅稿为依据。

## 1. 画布与间距

| 项 | 值 |
| --- | --- |
| 画布 | 1280×720，16:9 |
| 内容左右边 | x=96–1184，宽1088 |
| 顶部保护区 | y≤120：原左上标识、叶片与标题；无通栏蓝带 |
| 正文区 | 通常y=162–443；容量不足先凝练、换页型或拆页 |
| 结论带 | y=480–560；极浅蓝底，左侧4px蓝线 |
| 页码 | 基线580，13px灰字；不另加院系／作者页脚 |
| 建筑保护区 | 约y=585.5以下；正文和页码不压建筑 |
| 三栏 | 每栏320，间距64 |
| 四栏 | 每栏254，间距24 |

结论带的浅蓝底条、左侧强调线和文字须是每页独立对象：不组合、不锁定、不放入Master/Layout。底条与线保留原生矩形，文字保留独立文本占位符，分别可选中、编辑与拖动。

| 天蓝 | `#83BED9` | 图表次系列 |
| 清蓝 | `#579AB9` | 图表折线、内容细边；不用于标题序号 |
| 极浅蓝 | `#F0F8FC` | 结论带、证据区浅底 |
| 表头底／字 | `#E4F3FA` / `#56788B` | 浅底蓝灰字，不反白 |

- 不重染校徽、银杏叶、建筑；原资产渐变保留，新增内容禁阴影、3D、发光
- 浅色只用于较大文字；正文不随标题变淡。投影效果需实测，不能只凭屏幕确认

## 3. 字体与字号

全套使用 `Microsoft YaHei`／微软雅黑，不再依赖方正或华文中宋。缺字体先报告，用已安装中文字体替代并重新检查换行。

| 角色 | 字号 / px |
| --- | --- |
| 封面主标／副题 | 52 / 26 |
| 页标题 | 26.67；x=532.2起，框宽620 |
| 栏目标题／正文 | 24–26 / 20 |
| 栏目序号／目录序号 | 38–42 / 32 |
| 章节序号／章名／说明 | 88 / 42 / 24 |
| 图表标签 | 17 |
| 原生表格 | 表头20，正文20 |
| 结论正文／标签 | 22 / 13 |
| 来源、页码 | 12–14 |
| 结束页主字／副句 | 60 / 26 |

正文三行基线间距36；不为塞字缩小正文。标题、证据、结论保持分层。

## 4. 文案

- 一页一个结论；内容页标题优先6–12字，不用空泛栏目名
- 每页通常≤3条要点，每条≤18字，正文≤120字；四项并列页按4组槽位组织，不再额外叠加清单
- 凝练优先，不强制四字；章节副题可选，≤30字，不强制4+4
- 数字带单位、口径、来源；不把演示数据写成研究结果
- 禁词沿用校验器：赋能、抓手、闭环、生态、显著提升、全面提升、深度融合、助力、打造、护航
- 清除「单击此处」「请在这里添加」等占位文字；删减清单交代删了什么和原因

## 5. 页型与容量

| 原型 | 容量与行为 |
| --- | --- |
| `cover` | 主标单行≤18字；长题移副题或重排，不缩成小字 |
| `toc` | 3–5条；未用槽位置空 |
| `chapter` | 章号、凝练章名、可选说明 |
| `points3` | 三组标题和三行正文，结论一行 |
| `pillars4` | 四项并列；每项标题≤6字，说明2–3行 |
| `two_col` | 左≤3条；右证据区544×272，附图注 |
| `timeline` | 固定4节点；更多节点拆页，不硬塞5个 |
| `chart_column` | 原生柱状图，类别≤6、系列≤3 |
| `chart_combo` | 原生柱线图，左右轴各标单位 |
| `table` | 原生三线表；基准4列×4数据行，扩至6行×5列先校验容量 |
| `ending` | 致谢、副句、可选联系信息 |

不临时新增版式；修改容量时不得悄悄改变已复用Layout的槽位合约。

## 6. 原生图表与表格

- 从brief数据替换载体JSON；内置数值仅供审阅，全部替换，不保留模板来源说明
- `chart`／`table`槽位启用 `--native-charts-and-tables` 导出；不能把图片或普通形状冒充原生对象
- 图表用浅金与天蓝；组合图用浅金柱体＋清蓝折线；图例、线型和单位共同区分，不能只靠颜色
- 图表有单位、口径、来源；双轴缺单位则改单轴；图例优先底部
- 表格三线为清蓝，顶／底1.5px、表头下1px；无竖线、无斑马纹；数字右对齐，单位进表头
- 原生表格自定义边框需显式声明四边，避免Office默认竖线；浅蓝表头配蓝灰文字

## 7. 原始资产与标识

- 每页保留原左上完整可见组合，不擅自裁掉原有周年组合；不另加「120周年」文字或庆典页脚
- 原PNG校徽、银杏叶不重画、不重染；保留可见裁切、位置、旋转和翻转
- 建筑为原路径矢量组，引用唯一 `icons/imported/nju-campus.svg`；资产根保留 `data-icon-style="preserve-color"`，防止纵向压缩
- 线稿样张有轻微导入渲染差异，不宣称逐像素复刻；不使用旧版蓝底或示例照片
