# 交付前自检

当前默认：`nju-academic-ginkgo`，银杏金＋清浅蓝；旧蓝版不再参与验收。

## A. 内容

- [ ] brief校验退出0；页数与页面表一致
- [ ] 内容页标题为结论；文案凝练，不强制四字，副题≤30字
- [ ] 通常每页≤3条要点、每条≤18字；四项并列按原型4组组织
- [ ] 数字有单位、口径与来源；成稿不含模板演示数据
- [ ] 删减清单说明删去内容与理由

## B. 版式与底板

- [ ] 只用已确认11个原型；未悄悄改写共享Layout槽位合约
- [ ] 标题、正文未溢出；不靠缩小正文硬塞
- [ ] 正文止于建筑保护区上方，结论带y=480–560、页码基线580
- [ ] 序号和对应标题同为 `#B38B4A`，不再蓝金交叉
- [ ] 副题蓝灰、正文深灰；浅蓝仅在图表、细线和浅底
- [ ] 原左上标识完整、叶片姿态不变、底部建筑无拉伸和裁切
- [ ] 保留源底板已可见的周年组合；未额外加庆典文字、院系页脚或作者水印
- [ ] 无旧版蓝色横带、深蓝满版、右下校徽圆盘
- [ ] 浅蓝结论底条、强调线与文字是不同的Slide本地原生对象；未分组、锁定或留在Layout，分别移动不牵动其他对象／页面

## C. 原生图表与表格

- [ ] chart点开能改数据，table能增删行；不是贴图或普通形状拼表
- [ ] 载体JSON已用brief数据全部替换；开启 `--native-charts-and-tables`
- [ ] 浅金柱体 `#E2C98F`，天蓝次系列 `#83BED9`，组合折线 `#579AB9`
- [ ] 图表有单位、口径、来源；双轴左右单位均有；不只靠颜色区分
- [ ] 表格浅蓝底配蓝灰表头字；数字右对齐，无默认竖线或斑马纹
- [ ] 超出基准4列4行时复查容量；超过6行5列拆表

## D. 字体与实际软件

- [ ] 默认微软雅黑；如需替代已说明并复查换行，不依赖华文中宋
- [ ] 结构校验、原生对象检查、交付检查均通过
- [ ] 在目标软件中打开并导出；未测WPS、投影或缺字体环境时如实说明，不填已通过
- [ ] 浅色标题的投影可读性未被屏幕预览冒充验证

## E. 文案清理

- [ ] 无占位符、模板提示、演示来源说明或伪造数据
- [ ] 无禁词与错字；术语、数值、单位与brief一致

## 常用命令

先运行 `scripts/prepare.py`，以其成功输出中的绝对路径替换下面占位符。不注册全局模板索引。

```text
<python> <skill_root>/scripts/check_brief.py <project>/brief.md
<python> <ppt_master_root>/scripts/svg_quality_checker.py <template_root>/templates --template-mode --canonical-authoring
<python> <ppt_master_root>/scripts/apply_template.py <project> --root <template_root> --dry-run
<python> <ppt_master_root>/scripts/pptx_delivery_check.py <成稿.pptx>
```
