# 动效：按目的选择反馈、连续性与叙事

参考 taste-skill 的正向模式、huashu-design 的静态关键帧/节奏方法与 UI/UX Pro Max 的动效指导。**操作区短反馈，解释/展示区可以编排；它们可以在同一产品共存。** 不把宣传片镜头套到搜索/编辑，也不把“工作台克制”扩大为所有页面不得呈现。

## 先选动效的职责

| 内容需要 | 值得考虑 | 不适配时怎样退化 |
| --- | --- | --- |
| 告诉用户操作成功/内容已换 | hover、pressed、局部进入、保存提示 | 即时状态与文字仍清楚 |
| 同一对象从列表移到另一种视图 | 共享对象布局过渡、Morphing/FLIP 思路 | 保留选择和焦点，直接切换也能理解 |
| 信息需要按步骤理解 | 滚动章节、固定示意与步骤联动、分批揭示 | DOM 顺序完整，全部正文可直接阅读 |
| 同口径比较前后差异 | 切换/滑动对照、差异强调 | 并排静态对照与文本解释 |
| 有真实视觉主角的展示 | 短标题揭示、媒体入场、有限视差 | 无动效关键帧本身成立，资源不可用有替代 |
| 持续监控/高频输入 | 小范围数据变化提示 | 不让整页重播，不滚动数字伪造进度 |

按内容、频率与设备确定节奏；140–180ms 是当前工作控件的起点，不是所有展示动效的上限。先设计停顿帧，再设计变化；一个关键细节精修，其他部分安静。

## 在哪里体验

- [设计探索](../assets/ui-lab/design-exploration.html)：同一对象列表/流程重排、自然滚动的章节联动、原生弹层；候选，不是固定模板
- [组件实验室](../assets/ui-lab/index.html#motion)：点击顶部「体验动效」或侧栏「交互动效」；也可操作节点/指标切换、菜单、新建实验与详情

下面保留现有工作型样板的实际参数，不要求新页面照抄。

| 场景 | 目的 | 当前演示 |
| --- | --- | --- |
| hover / focus / pressed | 说明整行可点击、当前选中与键盘落点 | 约 140–180ms；导航轻浮 1px、按下 .985 微压，布局不重排；focus 保持圆角 |
| 菜单 / 详情弹层 | 解释内容从操作附近出现 | 160ms，透明度 + 6px 位移；关闭即时，不阻碍返回 |
| 指标 / 状态 / 对象切换 | 说明内容已换，不让用户误以为还是上一条 | 180ms，透明度 + 4px 位移；数据即时更新，不等动画 |
| 渐进展开 | 摘要保持安静，细节按需出现 | 原生 details，展开内容短反馈；不是复杂弹窗 |
| 保存反馈 | 操作有结果，仍可继续工作 | 160ms 提示出现，无无限循环 |
| 长等待 | 说明正在处理，不伪造进度 | 按钮加载态、禁用重复提交；完成后恢复 |

## 取舍

- 一个变化一个解释。数据变化、容器位移、数值滚动不同时抢注意力
- 频繁操作用短反馈；不要每次搜索让整张表重新进场
- 局部内容变了就动局部；高频操作不插值整页栅格。**低频探索/演示**可以做共享对象重排，要保留文本可读与焦点
- 操作区由用户触发；阅读/展示区可按自然滚动揭示，不劫持滚轮、不把正文藏到动画播放后、不让真实数据曲线循环重绘
- `prefers-reduced-motion: reduce` 时取消进入动效、即时更新。仍保留焦点与选中反馈
- 原生 CSS 与 Web Animations API 足够时不引入动效库；需要复杂编排再读外部 skill 的配方

## 验收

真实点击后检查：结果立即可见、焦点可返回、没有溢出和布局跳动、减少动态效果下仍能操作。
截图检查静态构图；真实操作检查节奏。两者都不等于用户已认可最终观感。

复杂滚动叙事/动画先读 `huashu-design` 的 `storyboard-basics.md`、`animation-best-practices.md` 与 `animation-pitfalls.md`；UI/UX Pro Max 用 `--domain gsap` 查预设，核对实际强度与依赖。它们是方法来源，是否采用由当前区块的任务决定。
