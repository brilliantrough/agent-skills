# S04 · 分析排查工作台

## 1. 适用问题与证据边界

适用于追查“哪个对象，经由什么资源，在什么类别上，产生了多少消耗/事件”的任务。

- 已确认方向（T12）：功能驱动信息组织；联合排行、维度合并、分层展开与组合明细。
- 下述图形选择、状态处理与验收是由实例提炼的方法；不表示用户已逐项认可所有场景的视觉细节。
- 不把多维排查套到所有页面。只有单一总量、纯状态监控或编辑任务时，采用更直接的界面。

典型反例：对象排行、资源排行、类别排行各自完整，用户仍得来回切页才能猜出它们的关联。

## 2. 从问题选表示方式

| 用户任务 | 优先考虑 | 条件与边界 |
| --- | --- | --- |
| 精确找最大组合、复制名称核查 | 联合排行表，标识/备注＋指标，按相关指标排序 | 保留联合键，不能拿独立排行拼关系 |
| 按不同入口逐层追查 | 分组小计＋折叠展开，选择优先分组 | 层级是探索顺序，不强称为实体的永久父子关系 |
| 忽略一类差别比较规模 | 保留维度开关或分组选择 | 真正汇总，不是仅隐藏一列；指标须支持该汇总 |
| 何时突增、是否持续 | 选中组合的时间趋势 | 继承对象与范围，区分缺测和零 |
| 查具体记录/原始目标 | 显式明细入口，保留返回路径 | 备注方便识别，不代替稳定身份 |
| 少量两维对象交叉比较 | 可考虑矩阵/热图，保留精确值入口 | 名称或维度基数太大时仍以表格/筛选为主 |
| 查看少量类别间的流量分布 | 口径适合时可补流向图 | 不因“流向”二字默认画复杂图；精确排序和检索仍要可达 |

先完成主要排查路径。总量卡片、图形、表格和树不是必须全部出现的套餐。

## 3. 合并与折叠同时存在时

| 操作 | 用户应该看到 |
| --- | --- |
| 保留全部维度 | 每行一个具体组合 |
| 取消某维度 | 跨该维度汇总，其余维度仍可区分 |
| 折叠某一组 | 小计保持，子项暂不显示 |
| 展开 | 显示下一层及各自小计，范围不跳变 |
| 切换优先分组 | 从另一个维度开始探索，总量保持 |
| 切到平铺 | 相同范围的组合直接比较，不遗留隐藏业务筛选 |

示意：对象甲经资源一用300单位、经资源二用600单位，均属于类别A。

- 保留对象＋资源＋类别：两行，300与600。
- 保留对象＋类别：一行900；资源被汇总，不是两行都藏起资源名称。
- 树按对象展开：父小计900，展开资源后看到300与600；折叠不改变900。
- 已筛选资源一，再取消资源维度：仍是300；汇总维度不解除筛选。

固定顺序足够时不做拖拽排序器。确有不同排查入口，再提供优先分组；至少保留一个维度，或明确单独定义“仅总计”状态。

## 4. 去除语义重复，保留必要区别

- **分类/动作与资源分工**：绕过、拒绝、失败等可能是处理结果，并非真实资源。依据模型中的类型分类，不仅按名字判断。
- **依赖筛选**：选到不适用资源的状态时，清空并禁用资源条件，或采用产品已定义的联动；切换后可见条件必须与查询一致。
- **展示层含义清楚**：无资源可以显示“—”，旁边保留原因或路由状态，不能让不同处理结果变成同一个无法解释的空组。
- **混合范围有提示**：选“全部”后再选一个资源，如果这会缩小到某一类别，界面同时更新类别，不留下“全部”的假象。
- **特殊值可区别**：“全部”“未归类”“未知”“空名称”和真实同名项分别处理，不能用业务名称充当内部哨兵。
- **独立口径写明**：全局告警若故意不跟随局部筛选，标题/说明明确范围；不要为了看似联动而改变告警定义。

## 5. 完整数字与连续操作

- 小计代表完整匹配范围；分页、加载更多、折叠或只加载前N条不改变它。截断结果必须标明。
- 每层可延迟加载；加载、空、失败、重试清楚可见，某层失败不冒充没有数据。
- 展开身份使用稳定组合键；排序、刷新后不能把展开状态错套给同下标的另一对象。
- 筛选、分组、明细范围有统一来源；旧请求返回不能覆盖新条件。变化后已无效的明细或焦点清除。
- 明细标题显示当前组合；返回后仍能知道来源筛选、分组入口和位置。不要让用户重新构造刚才的查询。
- 表格与分组尽量紧凑；长名称保留可读或可访问的完整内容，表格局部横滚，按钮和原生折叠支持键盘。
- 实时窗口的小计会变化，明确更新时间；固定历史对账不要拿不同时间的页面值比较。

## 6. 验收一条真实排查路径

1. 使用同一对象跨两个资源、不同对象共享资源的可解释数据；确认联合关系没有被边际排行替代。
2. 改维度后比较可加指标总量；检查取消维度与保留筛选同时存在的情况。
3. 展开、折叠、换优先分组、翻页；父小计完整，叶子明细继承正确范围。
4. 检查未归类、非适用资源、空态与失败重试；“没有观察到”不写成“没有发生”。
5. 真实进入趋势/明细再返回；当前条件可辨认，旧请求不覆盖新视角，键盘可操作，窄屏不撑宽整页。

只做本次功能需要的检查。复用现有图表时沿用共享交互模式，不复制一套新的tooltip规则；涉及指标合并、快照采集、留存、清理或重启恢复时，按任务读 [数据与运行约定](../references/data-and-runtime.md) 的对应小节。
