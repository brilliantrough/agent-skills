# S03 · 科研指标绘图

适用：实验指标看板、训练曲线、方法对比图等科研可视化。继承 S01 的浅色信息密集基线与 T05/T06/T11 的图表偏好；本场景规定**数据形态 → 绘图方式**的映射。核心品味：图上每个元素都要承载比较价值，不允许“孤零零”的数据存在；先想清楚数据之间是互斥还是可叠加，再选分页还是同画布。

## 1. 总原则

1. **形态决定图形**：先看数据是什么（标量、单曲线、多族曲线、稠密序列、多口径），再选画法；不允许拿到什么画什么。
2. **共享横轴 → 同画布叠加**：多条曲线有相同横坐标（epoch、step、时间）就能放在一起比较，用图例/族开关控制可见性——这是**非互斥**的叠加，不拆页面。
3. **实验批次互斥，其余维度可见性切换**：只有"不同性质的实验批次"（用户说"这组数据是一组实验"的那个组）之间才互斥分页；数据集、方法族、平台等比较维度默认**每个数据集一幅图 + 可见性开关（隐藏/显示）**，不做互斥下拉。判断标准：用户把哪些数据当"一批实验"，哪里才是边界。
4. **比较优先**：每条线、每个点、每条参考线都要能回答"和谁比、差多少"；不能参与比较的元素不放上去。
5. **灵活优先**：控件是视角切换器，不是永久筛子；任何时候一键回到"全部"。
6. **折线是主视图**：多 run 指标对比不用柱状图——横排柱状图难看、看不出趋势与差异量级；指标选择器直接放在折线图头部。
7. **图例放图右，互补形状**：曲线图占满页宽时本就偏长，图例面板不要放在图下方（纵向空间被压扁、条目少、还要滚动）；放图右侧纵向排列、与图同高、内部滚动，条目里的文字和数值才有地方展开。窄屏（<760px）退化为图下方。

## 2. 数据形态 → 绘图方式

| 数据形态 | 绘图方式 |
| --- | --- |
| 标量固定值（原始基线、PTQ 起点等单次评测） | **横贯全图的虚线参考线（水位线）**，线尾标注“名称 + 数值”；静态、不抢 hover、不进图例开关。**禁止画成孤立点**——单点不参与曲线、不承载趋势，是视觉垃圾。**参考线常驻**：不随评测口径、方法族筛选消失；原始预训练基线无条件常驻，中间阶段锚点（如量化起点）在实验批次涉及时才加（同组基线视图、或曲线方法名提及）。锚点族不得作为族控件里的可选“页面”——点过去只剩参考线没有曲线，没有意义 |
| 单方法、逐 epoch/step 的曲线 | 折线 + 圆点，tooltip 显示该点全部指标 |
| 多方法族共享横轴 | 同画布叠加 + **方法族筛选控件**（全部/各族、带数量、族<2 时隐藏）；同族内不同变体用颜色/线型区分，重名曲线必须唯一命名（见 patterns.md §1 图例踩坑） |
| 同一 run 的多口径（如回调 vs 独立重载） | 同族双线型：实线/虚线、圆点/菱形，同色系表达“同一方法、两种口径” |
| 稠密长序列（几千 step 的 loss） | 折线无圆点 + 横纵 dataZoom 滑条；不平滑、不补值，抽稀必须在说明里写明 |
| 多 seed / 多重复 | 同族并列或聚合带；未确认聚合方式前不擅自平均，重复次标记 #1/#2 |
| 同性质的多个数据集 | **每个数据集一幅折线图**，块头提供可见性开关（隐藏/显示，非互斥下拉）；隐藏状态进 URL hash 可分享 |
| 互斥的实验批次 | 分页签/筛选器；只有"不同性质"的批次之间才互斥，用户明确说"放在一起比"时例外 |
| 缺数据/失败的 run | 留空或灰显，状态用文字说明；**不把未知画成 0**，不把失败曲线混进成功族 |

## 3. 品味禁忌

- **孤立点**：任何"不参与曲线、又不是参考线"的单个点都是错的——要么它是水位线，要么它不该在这张图上。
- **指标横排柱状图**：多 run 的准确率/F1 排成柱状图难看且看不出趋势；主视图一律折线。
- **过度互斥**：把数据集/方法族做成"只能选一个"的下拉是错的——可叠加比较的维度用可见性开关，只有不同性质的实验批次才互斥。
- **假趋势**：单点连成线、把缺测插成 0、平滑产生超出数据范围的视觉值，都是欺骗。
- **一图塞全家**：互斥维度同画布=无法读；可叠加维度拆页面=无法比。先判断互斥性再动手。
- **控件状态说谎**：图例/族开关的亮灭必须等于曲线真实可见性（patterns.md §1）。

## 4. 验收

- 找一张多族曲线图：点开族控件，断言只剩该族，相关图（如 Loss）同步，回"全部"恢复。
- 多数据集视图：每个数据集一幅图；点"隐藏"后该数据集的指标图和 Loss 图同步隐藏、URL 带状态；点"显示"恢复。
- 桌面宽度下图例面板在图右侧纵向排列且与图同高；窄屏退化为图下方。
- 找一条标量基线：确认它是横贯参考线且带标注，而不是孤立点。
- 切换评测口径和方法族：原始基线参考线仍在；锚点族不出现在族控件按钮里。
- 找一条稠密 loss：确认可缩放、无圆点、说明里有采样口径。
- 空筛选/失败 run：显示空态或灰显说明，不画假数据。
