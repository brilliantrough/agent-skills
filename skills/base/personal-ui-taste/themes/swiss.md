# Swiss Modernism 2.0 · 极简专业主题

- 来源：UI/UX Pro Max #50；2026-10-04 用户对比验收 Confirmed。
- 气质：数学网格 + 发丝线 + 单一强蓝；层级全靠网格、字重与黑线，不用阴影。
- 默认适用：文档型界面、正式/对外场景、需要极强秩序感的专业工具。

## Tokens

| 项 | 值 |
| --- | --- |
| 字体 | Inter；数字 tabular-nums |
| 表面 | canvas `#ffffff`；panel `#ffffff`；control `#f4f4f5` |
| 文本 | primary `#111114`；secondary `#5f6368` |
| 边界 | `#e4e4e6`；强 `#111114`（黑线用于顶栏/侧栏骨架） |
| 强调 | accent `#2547f4`（唯一彩色）；selected `#eef1fe` |
| 图表色 | `#2547f4` + 灰阶 `#111114` `#8a8f98` `#c9ced6` `#5f6368` |
| 状态色 | ok `#0a7d4f`；warn `#b57708`；bad `#c92a2a` |
| 圆角 | 2–4px（近直角） |
| 阴影 | 无；浮层仅 `0 4px 24px rgba(17,17,20,.12)` |
| 动效 | 120ms / 200ms ease |

## 组件处理要点

- **骨架线**：顶栏底部 2px 黑线；侧栏 1px 强边界；面板 hover 时边界转黑（不加阴影）。
- **导航**：直角；活跃项不加底色，左侧 3px accent 色块指示。
- **分段选择**：活动项黑底白字。
- **灯带/标签/品牌点**：全部直角实色。
- 网格：12 列、8px 基准单位；不要把本主题圆角加大或加投影。
