# shadcn Neutral · 现代简洁主题

- 来源：[shadcn/ui](https://github.com/shadcn-ui/ui)、[主题语义](https://ui.shadcn.com/docs/theming)与官方组件示例。
- 认可：2026-10-04 用户明确表示相较早期亮蓝描述，更喜欢这里的现代、优美、简洁设计，要求纳入正式主题选项。参考方向 Confirmed；下列起点与新实现尚未逐项目验。
- 气质：中性色调、精细边界、清楚排版、统一组件比例；彩色集中在需要识别的数据与状态上。
- 适用：工作台、管理台、设置、内容界面；新页面优先推荐，已有产品沿用所选主题。

## Tokens 起点

这是从参考方向提炼的一种中性实现；shadcn 支持多种色板与样式，不能把这张表当作其唯一官方主题。

| 项 | 浅色起点与用途 |
| --- | --- |
| 字体 | 项目已有现代无衬线，或评估 Geist / Inter；中文明确配对 Noto Sans SC 或已有中文 UI 字体；数字 tabular-nums |
| 表面 | background `#ffffff`；card/popover `#ffffff`；muted/hover `#f4f4f5`；侧栏可用 `#fafafa` |
| 文本 | foreground `#18181b`；muted-foreground `#71717a`；不靠整体降低文字对比制造轻盈 |
| 主操作 | primary `#18181b` + 白字；hover `#27272a`；次操作白底细边界或浅灰底 |
| 边界/焦点 | border/input `#e4e4e7`；focus-visible 用可辨的轮廓与间隔，不能只把细边框略微变灰 |
| 选中 | 浅中性底 + 深文字，必要时配勾选/指示条；不默认染蓝 |
| 图表/状态 | 独立语义色；科研曲线可保留已认可的明亮蓝紫青绿，状态继续红黄绿，不随壳层一起灰阶化 |
| 圆角 | 当前个人变体：导航/搜索/分段控件为胶囊；普通控件 10px、面板 14px、大容器 16px；不把大面板做药丸 |
| 阴影 | 按钮/卡片无或极轻阴影；菜单/弹窗用轻阴影明确浮层，不层层加厚 |
| 动效 | 约 140–180ms 的底色、边界、轻阴影；导航 hover 上浮 1px、按下缩至 .985；减少动态效果时取消位移与缩放 |

## 侧栏与页面骨架（2026-10-08 实测 ui.shadcn.com/docs）

用户 2026-10-08 指定左导航照线上 docs 侧栏做。下表保存当时从线上 DOM 与 computed style 量到的参考值。**当前导航采用下节的个人圆润变体**，不再照搬 30px 小条目与贴合文字宽度；线上实测不是用户偏好的上限。

| 项 | 实测值 |
| --- | --- |
| 侧栏列宽 | 288px；菜单列 224px（分组左右各 8px 内边距） |
| 分隔线 | 不用 `border-right`：右侧 8px 处 1px 竖线，`linear-gradient(transparent → border 10% → 90% → transparent)` 上下淡出 |
| 分组标题 | 高 32px、左右 8px、12px / 500、用次级文字色；不做大写转换 |
| 条目 | 高 30px、内边距 8px、圆角 **8px**、字号 **12.8px** / 500、**药丸宽度贴合文字**、自带 1px 透明描边 |
| hover 与选中 | 同为浅底（线上 `#f5f5f5`）+ 文字转正文色；选中额外把那条描边染成同色，切换时不跳动 |
| 静止文字 | 正文色，不是灰；只有分组标题降一级 |
| 页面 | 线上是**纯白扁平**（侧栏与内容同底色）。用户另选了 shadcn Sidebar 组件的 `variant="inset"`：页面底 = `--canvas`，侧栏 = `--side-bg`，内容区 = `--panel` 圆角面板 + 8px 外边距 |

## 当前个人变体（2026-10-08 · T14）

用户明确喜欢圆润框、同组等宽且容易点击的按钮，以及现代 hover/按下反馈；此反馈取代早先“贴合文字的小号条目”实现。

- 导航：整行等宽、高 42px、字 14px、胶囊边界；短标题与长标题共用命中区
- 搜索：高 40px、胶囊轮廓；hover 边界可辨，focus 保持圆润并出现焦点环
- 状态：常态透明、无可见描边和阴影；hover 轻浅底色，选中常驻浅灰高亮与字重；圆角和整行命中区不因隐藏轮廓而缩小，按下微压仍保留
- 分段导航：圆润轨道与内层胶囊；结构切换按钮同组等宽，窄屏两列
- 原生键盘/链接行为保留；减少动态效果时即时换色、取消位移缩放

## 组件落地

- **按钮**：主、次、outline、ghost、危险操作按动作权重选；同排统一高度与图标尺寸。loading 保持宽度，焦点与禁用态仍清楚。
- **输入与筛选**：标签、说明、输入、错误信息各有层级；对齐共享基线。用细边界和 focus-visible 建立可操作性，不把所有控件包成小卡片。
- **导航**：轻中性表面与分组保留；按 T14 做圆润等宽命中区，选中/hover/按下分开。选择本主题不强制改变侧栏、顶栏或页面结构。
- **菜单与浮层**：触发器、搜索、选中勾、分隔与快捷键排版一致；复用组件的键盘/焦点行为，长列表滚动和贴边定位需要实跑。
- **列表与表格**：行分隔轻、主次文字清楚；操作就近且不挤压内容。保留表格的信息密度，不为模仿示例增加卡片层级。
- **总览**：静态读数优先开放排列，不加无数据支撑的小波形；卡片用于独立对象或操作，不是数值的强制外壳。
- **摘要卡**：标题/对象 → 核心数字及单位 → 范围或比较 → 次要指标/详情；内容关联紧密才合为一张卡。
- **图标与标签**：操作图标用同一套；品牌图标按需使用 Simple Icons；状态与身份标签遵循 [共用做法](../references/visual-craft.md)。

## 技术栈与复验

- React 项目可按需采用 shadcn 源码组件，先接项目语义 tokens；已有组件库或静态页面也能吸收比例、状态与排版，不因选主题就迁移框架。
- 沿用项目已选的组件底座；Radix Colors 仅负责色阶，和 Radix 交互组件分开判断。
- 明暗切换按任务决定；深色版要独立检查灰阶、浮层和图表，不由浅色参考自动推定认可。
- 同一画面检查中英文、数字、长名称、菜单贴边、hover/focus/selected/disabled，以及状态和多系列图表。技术跑通后，具体观感仍由用户反馈确认。
