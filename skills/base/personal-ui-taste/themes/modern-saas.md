# Modern SaaS · 浅色亮蓝

- 来源：早期 SaaS/Analytics 色板实验。2026-10-04 认可鲜艳状态灯带；2026-10-08 明确拒绝新版大片黑底，旧“整体 Confirmed”不再代表当前样板
- 当前方向：浅色导航与内容，亮蓝只用于主操作和选中；去掉导航渐变、品牌辉光与曲线光晕
- 适用：需要亮蓝的 S01/S04 工作台；不是默认优于 shadcn。替代实现 Candidate，待目验

## Tokens

| 角色 | 值 |
| --- | --- |
| 字体 | Inter / Noto Sans SC；数字 tabular-nums |
| 画布与导航 | `#f8fafc`；内容 `#ffffff`；控件 `#f1f5f9` |
| 文字 | 主 `#172033`；次 `#5c6778` |
| 边界 | `#e5eaf0`；强 `#bdc7d5`；输入 `#d5dde7` |
| 强调 | `#2563eb`；hover `#1d4ed8`；选中 `#eff6ff` |
| 图表 | 蓝、紫、青、琥珀、玫红用于不同系列；同一指标分类柱共用一色 |
| 状态 | `#22c55e` / `#f59e0b` / `#ef4444`；徽章另用深色文字 |
| 圆角 | 控件 6；面板 10；大容器 12 |
| 动效 | 140ms / 220ms；公共内容反馈见 [motion.md](../references/motion.md) |

## 组件处理

- 导航浅底与深文字，选中用浅蓝；没有霓虹指示条
- 总览读数去独立卡框，用对齐与竖向细分隔建立分组
- 主按钮蓝底白字，hover 轻微变深，不加外发光
- 已认可的灯带保留鲜明红黄绿和局部 hover 反馈，不扩大成整页辉光
- `--canvas` 管页面，`--side-bg` 仅管侧栏；透明主区不得借到另一角色的深色底

## 反馈边界

新反馈否决的是当前黑底样板，不据此禁止所有深色产品；旧灯带认可仍有效。用户喜欢的是可读、鲜明的信号，不是深色侧栏的强制组合。
