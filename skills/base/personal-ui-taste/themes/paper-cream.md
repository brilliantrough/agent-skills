# Paper Cream · 暖白纸面

- 来源：用户指定 [code.claude.com/docs](https://code.claude.com/docs) 的观感与米色；2026-10-08 从线上 DOM 与 computed style 取实测值（非印象描述）。
- 气质：暖白纸面 + 暖灰文字 + 单一陶土强调；标题与数字用衬线，正文无衬线；层级靠发丝线，几乎不用阴影。
- 默认适用：文档型与阅读型界面、需要"安静但不冷"的产品页；也用于工作台，此时密度仍按 S01 处理，不因主题放大字号。

## 组件处理要点

- **标题/数字**：衬线承载"文档感"，`h1` 32px / 字重 500；KPI 数值同族，字重 500 配 tabular-nums。
- **导航**：与画布同底色，右缘 1px 上下淡出的暖灰竖线；选中是浅米药丸，描边同色，切换不跳动。
- **主按钮**：扁平陶土实底、无阴影、按下不下沉；次按钮用米面 `--control`，不用厚描边。
- **面板**：发丝线 + 暖灰层次，不加阴影；`.grid > .panel` 沿用 base 的无框下分割线，正是文档流的样子。
- **图表**：曲线用暖色打头，状态色降饱和；灯带与徽章用米底 + 深字，避免荧光感。
- **注意**：陶土是暖色，与 `--bad` 红同属暖区，错误态要靠图标/文字并存区分，不能只靠色相。
