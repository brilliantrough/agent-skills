# Soft UI Evolution · 柔和亲和主题（降亮版）

- 来源：UI/UX Pro Max #19；初版整体太亮刺眼被用户指出，2026-10-04 降亮后 Confirmed，复验待定。
- 气质：柔和多层阴影 + 圆润粉彩，控件像从画布轻轻浮起；保持 4.5:1 对比，不做新拟态糊。
- 默认适用：轻量/亲和向工具、表单为主的设置页。

## Tokens

| 项 | 值 |
| --- | --- |
| 字体 | Nunito（圆润人文无衬线）；数字 tabular-nums |
| 表面 | canvas `#e6eaf2`（已降亮）；panel `#fbfcfe`；control `#e6eaf3` |
| 文本 | primary `#2b3245`；secondary `#69718c` |
| 边界 | `#e3e8f4`；强 `#ccd5ea` |
| 强调 | accent `#5b8def`；hover `#4678de`；selected `#e6edfd` |
| 图表色 | `#5b8def` `#9b7bea` `#4ec4b6` `#f2a65a` `#ef7ba0` |
| 状态色 | ok `#2e9e6b`；warn `#cf8f1f`；bad `#dc5f6e` |
| 圆角 | 控件 10；面板 14；卡片 18 |
| 阴影 | 平铺 `0 2px 5px rgba(69,82,120,.07)`；hover `0 8px 20px rgba(69,82,120,.11)`；控件 `inset 0 1.5px 3px rgba(69,82,120,.08)` |
| 动效 | 200ms / 300ms ease（本主题动效偏慢，配合柔和气质） |

## 组件处理要点

- **控件**：输入框/分段轨道用内阴影凹入，按钮与导航活跃项用外阴影浮起，形成"按得下、浮得起"的材质逻辑。
- **按钮**：字重 700，按下下沉 1px。
- **焦点**：`:focus-visible` 用 3px `rgba(91,141,239,.55)` 粗环（柔和主题下细环看不见）。
- **标签**：字重 700。
- 警惕亮度回弹：canvas 不得亮于 `#eef2f9`（初版刺眼教训）。

## 用户反馈记录

- 2026-10-04：初版"太亮了，看的有点刺眼"；降亮后用户未再复验，使用时先小范围落地再请其目验。
