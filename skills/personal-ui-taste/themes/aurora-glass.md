# Aurora Glass · 玻璃质感主题（去渐变版）

- 来源：UI/UX Pro Max #10 + #3；初版多色极光渐变背景被用户否决（"看着别扭"），2026-10-04 去除渐变后 Confirmed。
- 气质：平色浅蓝画布 + 磨砂玻璃面板，轻盈通透；玻璃只作表面材质，不做背景特效。
- 默认适用：需要玻璃浮层/毛玻璃导航的场景；作为其他主题的浮层材质也可借用。

## Tokens

| 项 | 值 |
| --- | --- |
| 字体 | Inter；数字 tabular-nums |
| 表面 | canvas `#dfe6f5`（平色，仅允许顶部一处 `rgba(0,128,255,.07)` 的极淡径向提亮）；panel `rgba(255,255,255,.62)` + `blur(16px)`；control `rgba(255,255,255,.55)` |
| 文本 | primary `#17203a`；secondary `#4d5878` |
| 边界 | `rgba(255,255,255,.65)`；强 `rgba(255,255,255,.9)` |
| 强调 | accent `#0080ff`；hover `#006fe0`；selected `rgba(0,128,255,.12)` |
| 图表色 | `#0080ff` `#8b5cf6` `#00c2b8` `#f59e0b` `#ff4d8d` |
| 状态色 | ok `#0d9d63`；warn `#d08a00`；bad `#e0425e`（标签用 12–15% 透明底） |
| 圆角 | 控件 10；面板 14；卡片 20 |
| 阴影 | `0 2px 8px rgba(40,55,100,.08)`；浮层 `0 18px 48px rgba(40,55,100,.22)` |
| 动效 | 160ms / 260ms ease |

## 组件处理要点

- **面板/卡片/图例**：统一 `backdrop-filter: blur(16px)` 玻璃。
- **侧栏/顶栏**：`rgba(255,255,255,.45–.5)` + `blur(18px)`。
- **主按钮**：`linear-gradient(120deg, #0080ff, #6a5cff)` 蓝紫渐变（按钮面允许，背景不允许）。
- **焦点曲线**：`drop-shadow(0 0 5px rgba(0,128,255,.5))`。
- **灯带**：段带 `0 0 8px currentColor` 辉光。
