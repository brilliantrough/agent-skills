# 参考例子 · 实验指标看板（脱敏）

这是 S03 规则的一个完整落地实例，从一个真实的量化实验看板抽取并脱敏：数据集、方法名、平台名均已泛化。供设计同类页面时对照结构，不照搬样式数值。

## 数据模型（与绘图无关的部分略）

每条记录是一次评测：

```
{ platform, model, task, group, role(baseline/method/ablation),
  surface(训练时/重载后), lr, seed,
  points: [{kind:"p0"|"epochN", accuracy, macro_f1, mean_choice_nll}...],
  loss_curve: [[step, loss]...] }
```

关键性质，决定了画法：

- **标量锚点**：`points` 只有单个点、没有 epoch>0 的记录（如原始基线、量化起点）→ 参考线。
- **曲线**：有 epoch 序列 → 折线。
- **稠密序列**：`loss_curve` 几千点 → 无圆点折线 + 缩放滑条。
- **同实验多口径**：同一 run 的"训练时"与"重载后"两份 points → 同族双线型（实线/虚线）。

## 页面结构

```
侧栏（互斥维度，选了 A 就不看 B）
  模型 / 实验批次 / 数据划分 / 口径 / 指标快照 / 学习率
顶部：平台切换条（多机同图 / 各机器）
主区：
  验证指标面板
    头部：指标选择器（准确率/F1/NLL）+ 方法族开关（全部/各族）+ 导出
    按数据集分块，每块：块头（数据集名 + 曲线数 + 隐藏按钮）
      [折线图（占剩余宽度） | 右侧纵向图例（与图同高，内部滚动）]
      图例每行：线型样例 + 唯一曲线名 + 末次值；点击切换可见性
      图上：锚点画横贯虚线参考线，线尾标注名称+数值
  训练 Loss 面板：同样按数据集分块，无圆点折线 + 双轴缩放滑条
  结论卡片 / 注意事项 / 明细表（与图同一筛选口径）
```

## 这套结构对应的 S03 决策

| 数据形态 | 这里怎么画 |
| --- | --- |
| 原始基线（标量） | 无条件常驻的虚线水位线 |
| 量化起点（标量） | 该实验批次涉及时画水位线 |
| 方法 A vs 方法 B（逐 epoch） | 同画布叠加，头部族开关隔离单族 |
| 每方法两种口径 | 实线=训练时，虚线=重载后，同色 |
| 两个数据集 | 两幅折线图并排分块，块头隐藏/显示（非互斥） |
| 实验批次之间 | 侧栏互斥筛选 |
| 几千 step 的 loss | 无圆点折线 + 双轴缩放，不平滑不补值 |
| 失败/未完成的 run | 曲线留空，明细表文字标注状态 |

## 踩过的坑（对应 patterns.md / S03 验收）

1. **图例按名字选系列**：同一方法多个变体被简称折叠成同名，开关状态与可见性错位 → 重名加变体尾缀，保证唯一。
2. **水位线被纵轴自动缩放裁掉**：markLine 不参与 axis extent → y 轴 min/max 显式包含参考线值。
3. **锚点被筛选器误伤**：参考线若跟随口径/族过滤，一切换就消失 → 参考线独立计算，只跟随平台/模型/划分。
4. **标量混进曲线横轴**：锚点的"起点"刻度污染 epoch 轴 → 曲线图的横轴只从真实曲线收集。
5. **互滥用互斥**：数据集做成"只能选一个"的下拉 → 改为每数据集一幅图 + 可见性开关。
