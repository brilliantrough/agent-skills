# S02 · 冷灰蓝预览型工作台

适用：图片/文档/作品预览、快照画廊、少量离散状态且每格可跳转的工作台。继承 T02–T04 的统一字体、克制边界与全站一致性。

**已确认**：用户明确喜欢现有界面的主题、按钮、字体、卡片与大矩形框；允许稀疏状态与密集细灯带并存。主题和元素语言可迁移到其他工作型界面，卡片布局仅在内容值得预览时采用。

## 1. 主题：冷灰蓝层次 + 蓝紫强调

下面是从已认可前端源码提炼的成组参考；复用色彩角色和层次，不把所有项目锁死到这些数值。

| 角色 | 浅色参考 | 配对深色参考 |
| --- | --- | --- |
| 画布 | `#f5f7fb` | `#10141e` |
| 面板 / 默认控件 | `#ffffff` | `#191f2d` |
| 主文字 | `#233047` | `#e5eaf5` |
| 次级文字 | `#64748b` | `#95a2ba` |
| 细边界 | `#e1e7f0` | `#2c3548` |
| 蓝紫强调 | `#536de5` | `#a4b5ff` |
| 轻强调底 | `#eef1ff` | `#28314b` |

- 浅色默认：轻冷灰背景托起白面板，蓝紫只用于主要操作、链接和选中；状态绿/红/灰保持语义独立。
- 面板阴影近乎不可见，可参考 `0 8px 30px #24385606`；矩阵小卡不加阴影。浮层才允许更明显的层级阴影。
- 配对深色来自同一份源码，供同风格复用；使用深蓝灰而非纯黑/纯白反转，去掉面板投影，以表面与边界区分层次。用户未逐一确认所有深色组件，不扩大为深色全局偏好。
- 所有背景、文字、边框、浮层、focus 同步消费语义 tokens；原生控件同步 `color-scheme`，主题选择可持久化。

## 2. 字体与大矩形框

- 正文 `14px/1.6 system-ui, sans-serif`；按钮、输入、选择器继承同一字体。页面标题约 29px，分区标题约 19px，卡片名称约 14px；矩阵缩略卡可更紧凑。
- 辅助文字降低一级字号与颜色，主次来自层级而非堆粗体。时间数字可用 `tabular-nums`，不改成等宽控件。
- 大容器是**宽矩形 + 适度圆角**：细 `1px` 边界，面板/大卡约 13–14px，弹窗约 16px，小卡约 10px；不是巨圆角药丸，也不是硬直角代码框。
- 容器内部留约 16–20px，分区间隔约 24–30px；大框用于组织真实内容，不为一行数字堆空白。
- 源码中的小号字距装饰眉题可局部保留，但不因此把字段名或全站字体改为等宽；它不是必须复刻的组件。

## 3. 按钮、选择器与浮层

- 普通按钮：面板底、细边界、约 9px 圆角，内边距参考 `8px 12px`；hover 轻蓝紫底。与 S01 柔灰控件底并存，按主题保持一致。
- 主按钮实心强调色、对比清楚的文字；次按钮安静，危险动作只在对应操作出现。不要把主按钮 hover 或 disabled 的实际对比问题复制成审美规则。
- 分段选择：灰蓝轨道，活动项为面板底 + 蓝紫字 + 轻阴影，不用粗外框强调选中。
- 弹窗、原生 popover 与卡片共享圆角/边界；弹窗遮罩可用半透明深蓝灰 + 轻模糊。菜单保持短操作列表，次要详情可折叠。
- hover 约 150ms、图片缩放约 `1.015` 即可；焦点清楚、无布局跳动，遵守 reduced motion。

## 4. 内容卡片：预览优先，操作渐进展开

- 卡片以预览内容为主体，图片完整 contain 展示，底部一条紧凑信息行：名称、状态点、必要的短元信息。长说明和记录进入详情/菜单。
- 单组可用宽卡画廊，多组对比用矩阵小卡；参考小卡宽约 184px，图片纵横比跟随内容，不把此尺寸推广为所有缩略图的定值。
- 图片点击进入预览，列标题可进入对应组；次操作集中右上角 `⋯`，桌面 hover/focus 出现。触摸设备常显入口，不能依赖悬浮才能发现操作。
- 横向矩阵只在容器内部滚动，行名称/列标题可 sticky；最新内容保持易于到达。视图切换共享筛选状态。

## 5. 稀疏状态：保留可点击块，与密集灯带并存

- **稀疏 + 每格有跳转含义**：保留短矩形/近方形小块，源码参考约 `22×23px`、4px 圆角、4px 间距。块体不必强行压成细线，触摸时另保证可达命中区。
- **密集 + 看长期历史**：采用 S01 的细矩形灯带，见 [状态时间轴模式](../patterns.md#5-状态时间轴长细可解释)。决定因素是样本密度与交互目标，不是组件是否叫 uptime。
- 一格一次真实采样，不伪造连续在线时长；格子支持时间/状态说明，点击跳到相应内容。未知灰、未参与空缺在视觉与文字上区分。
- 不自动把两套密度混成一个折中组件；按场景选用，可在同一产品中共存。
