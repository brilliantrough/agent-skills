# 文献证据与科研数据图

本入口只管分工、工作区和交接。专业能力读取已安装的完整第三方 skill；不复制其脚本、图库或模板，不把项目改造成 Light-Science 的目录树。

## 1. 从真实任务选入口

先读已有项目画像、相关记忆与材料，确认这次需要什么。已有结论先复用，不把单篇阅读扩成综述、单张图扩成整篇论文流程。

| 当前问题 | 执行入口 | 完成依据 |
| --- | --- | --- |
| 找论文、核对引用、精读或翻译 | `literature-search`，实际源码目录名为 `light-literature` | 论文身份与版本、实际阅读范围、可定位证据和缺口 |
| 将已有真实数据做成科研图／表 | `light-chart` | 输入映射、统计口径、生成代码、图注、实际导出与目视检查 |
| 研究解释仍不清楚 | `exp-discuss`／`exp-workflow` | 先澄清主张、竞争解释与证据边界，不用一张漂亮图替代分析 |
| 需要新实验或矩阵 | `exp-campaign`／`exp-batch`／`exp-probe` | 沿用既有设计、执行与授权规则 |
| 方法／机制示意图或可编辑矢量重建 | `image-gen`／`editable-vector-slides` 等既有入口 | 科学关系、文字与实际可编辑文件核验，不冒充定量数据图 |

先读本地[版本与调用边界](references/light-science.md)，再从宿主技能目录找到真实安装位置，读对应上游 `SKILL.md` 和本次所需资源。典型共享位置为 `~/.agents/skills/<技能名>/`，不要假定当前目录在包内。

缺第三方能力时按该参考给出安装入口，也可继续已有可信工具路径；不能声称已执行上游工具、自动整包安装，或未经授权改宿主配置。

## 2. 先定工作区，再调用写文件的命令

- **已有布局优先**：用项目当前的文献、图件与分析位置；新任务只建本次需要的独立工作区。不搬旧文件、不补整套阶段目录、不把一篇论文定义强加给多路线项目。
- **分清输出目录与文件**：文献 `search --run`、`literature --out` 指向工作区目录；Chart `figure_job.py --out` 指向其中的 JSON 文件（如 `<图件工作区>/decision.json`），实际图件另指定导出路径。按具体命令核对目录存在要求及文件覆盖行为。
- **文献库不能以项目根为 `--out`**：工具会重写工作区的 `README.md` 与 `manifest.json`；已有手工 README 的目录也先比较，另建子工作区或经确认迁入。
- **内部契约不乱改**：保留所用工具的原生 JSON、文件名与身份字段；改变工作区位置，不做全局目录名／技能名替换。数据、模型、checkpoints 留原处，按项目约定引用。
- **不启用第二套底座**：不初始化 Light-Science 的 `Memory/`、`Workflow/` 或根 `project.json`。已有这些文件时仅按任务读取、不删除或迁移；新的跨会话知识仍走本项目的 `load-mem`／`save-mem`。

完成：写入位置与受影响的已有文件明确，包内资源、任务产物、项目记忆三者分清。路径约定是执行规则，不是脚本沙箱；实际命令和写后结果都要核对。

## 3. 保留专业能力，不夸大工具结论

### 文献

- 按问题选择来源、查询与停止条件；保留日期、检索式、失败／限额和未覆盖数据库。未检索到不代表不存在，普通多源检索不自动满足系统综述标准。
- 保留 DOI／版本、原文页码或结构锚点。元数据一致不证明原文支持主张；相关性分数、引用数不代替创新性或科学判断。
- 解析任务文件生成不等于读完 PDF。真实阅读后再交付解释、译文或笔记；缺全文／多模态能力时缩小结论，不补造内容。
- 内容变动保留旧稿和旧笔记，重新核对受影响主张；获取全文遵守授权，不绕过付费或访问控制。

### 数据图

- 先明确图要回答的科学问题，再选图型。输入用真实观测或已验证派生结果，保留样本／配置身份、配对、缺失、独立单位和不确定性定义。
- 展示变换与分析变换分开；不把舍入后的展示值覆盖原始数值，不用插值／装饰制造观测。合成演示须明确标注，不能混入研究结论。
- 沿用现有结果表与生成代码。只加载当前图型需要的上游资源；需要 Python／R 包时复用合适环境或经授权建隔离环境，不改共享训练环境。
- 查看实际导出：轴、单位、图例、误差条含义、字体、裁切与面板对应。脚本检查通过不代替科学与视觉检查；外部图库的许可单独核对。

## 4. 交接现有研究流程

交付实际路径、来源／版本、执行与检查范围、限制和下一步；按项目现有记录保存，不另造通用台账。图绑定所用数据与代码版本，论文引用确定的图件版本。

文献或图件变化若影响路线／主张，用 `save-mem` 记失效范围和待复核项；原始材料仍留工作区，不把全文、全部指标复制进记忆。后续实验仍交给 `exp-*`；本入口不自动调用 Light-Science 的写作、审稿、选刊、Leader 或 Memory。

## 演化

经验演化型：真实使用暴露路径冲突、证据误判或上游契约变化时，更新本入口的最小适配与固定基线。上游实现问题回原项目；安装副本不作为第二维护源。研究方法参考与安装细节见 [Light-Science 接入](references/light-science.md)。
