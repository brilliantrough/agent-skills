# 文献证据与科研数据图

本入口只管分工、工作区和交接。专业能力来自已安装的完整第三方 skill：直接读取使用，不复制其脚本、图库或模板，项目目录也保持原有布局。

## 1. 从真实任务选入口

先读已有项目画像、相关记忆与材料，确认这次需要什么。已有结论先复用；单篇阅读按单篇做，单张图按单张做。

| 当前问题 | 执行入口 | 完成依据 |
| --- | --- | --- |
| 找论文、核对引用、精读或翻译 | `literature-search`，实际源码目录名为 `light-literature` | 论文身份与版本、实际阅读范围、可定位证据和缺口 |
| 将已有真实数据做成科研图／表 | `light-chart` | 输入映射、统计口径、生成代码、图注、实际导出与目视检查 |
| 研究解释仍不清楚 | `exp-discuss`／`exp-workflow` | 先澄清主张、竞争解释与证据边界，再决定要不要画图 |
| 需要新实验或矩阵 | `exp-campaign`／`exp-batch`／`exp-probe` | 沿用既有设计、执行与授权规则 |
| 方法／机制示意图或可编辑矢量重建 | `image-gen`／`editable-vector-slides` 等既有入口 | 科学关系、文字与实际可编辑文件核验；示意图与定量数据图分开标注 |

先读本地[版本与调用边界](references/light-science.md)，再从宿主技能目录找到真实安装位置，读对应上游 `SKILL.md` 和本次所需资源。典型共享位置为 `~/.agents/skills/<技能名>/`；当前目录不一定在包内，以实际安装位置为准。

缺第三方能力时按该参考给出安装入口，也可继续用已有的可信工具路径。上游工具是否执行过，按实际情况报告；整包安装和改宿主配置都需要用户授权。

## 2. 先定工作区，再调用写文件的命令

- **已有布局优先**：用项目当前的文献、图件与分析位置；新任务只建本次需要的独立工作区。旧文件留在原处，不补建整套阶段目录；多路线项目不套用单篇论文的目录定义。
- **分清输出目录与文件**：文献 `search --run`、`literature --out` 指向工作区目录；Chart `figure_job.py --out` 指向其中的 JSON 文件（如 `<图件工作区>/decision.json`），实际图件另指定导出路径。按具体命令核对目录存在要求及文件覆盖行为。
- **文献库的 `--out` 不能是项目根**：工具会重写工作区的 `README.md` 与 `manifest.json`。目录里已有手工 README 时先比较，另建子工作区或经确认后迁入。
- **保留工具的内部契约**：原生 JSON、文件名与身份字段不改；只改变工作区位置，不做全局目录名／技能名替换。数据、模型、checkpoints 留原处，按项目约定引用。
- **只用一套底座**：不初始化 Light-Science 的 `Memory/`、`Workflow/` 或根 `project.json`。已有这些文件时仅按任务读取，不删除也不迁移；新的跨会话知识走本项目的 `load-mem`／`save-mem`。

完成：写入位置与受影响的已有文件明确，包内资源、任务产物、项目记忆三者分清。路径约定靠执行时遵守，没有脚本沙箱兜底；实际命令和写后结果都要核对。

## 3. 保留专业能力，不夸大工具结论

### 文献

- 按问题选择来源、查询与停止条件；保留日期、检索式、失败／限额和未覆盖数据库。未检索到时写“本次检索未覆盖到”；普通多源检索达不到系统综述标准时照实说明。
- 保留 DOI／版本、原文页码或结构锚点。元数据一致不证明原文支持主张；相关性分数和引用数是线索，创新性与科学判断另做。
- 解析任务文件生成之后还要真实阅读 PDF，再交付解释、译文或笔记；缺全文／多模态能力时缩小结论范围。
- 内容变动时保留旧稿和旧笔记，重新核对受影响主张。获取全文遵守授权，不绕过付费或访问控制。

### 数据图

- 先明确图要回答的科学问题，再选图型。输入用真实观测或已验证派生结果，保留样本／配置身份、配对、缺失、独立单位和不确定性定义。
- 展示变换与分析变换分开：原始数值保留，舍入只用于展示；插值和装饰不产生观测点。合成演示明确标注，并与研究结论分开。
- 沿用现有结果表与生成代码，只加载当前图型需要的上游资源。需要 Python／R 包时复用合适环境或经授权建隔离环境；共享训练环境不动。
- 查看实际导出：轴、单位、图例、误差条含义、字体、裁切与面板对应。脚本检查通过之后仍要做科学与视觉检查；外部图库的许可单独核对。

## 4. 交接现有研究流程

交付实际路径、来源／版本、执行与检查范围、限制和下一步，按项目现有记录保存。图绑定所用数据与代码版本，论文引用确定的图件版本。

文献或图件变化若影响路线／主张，用 `save-mem` 记失效范围和待复核项；原始材料留在工作区，全文和全部指标不进记忆。后续实验交给 `exp-*`。Light-Science 的写作、审稿、选刊、Leader 和 Memory 不在本入口范围内。

## 演化

经验演化型：真实使用暴露路径冲突、证据误判或上游契约变化时，更新本入口的最小适配与固定基线。上游实现问题回原项目；安装副本不作为第二维护源。研究方法参考与安装细节见 [Light-Science 接入](references/light-science.md)。
