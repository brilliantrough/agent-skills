# 从实验结果到有边界的结论

用于设计比较、解释结果和交接图表，按问题取用。记录沿用项目计划、结果表与阶段报告；统计检验、新表和新台账只在问题需要时才加。

## 先明确能区分什么

- 解释性研究：写清待证主张、至少一个合理竞争解释、关键对照和不同结果的含义。探索性研究可以先观察响应／交互，假设未知就写未知。
- 消融变更若同时改变参数量、训练步数、数据或算力，区分“整体配置效果”与“某组件／机制贡献”；无法隔离时降低主张强度。
- 明确实验／随机化单位、观察单位与配对／聚类关系。seed、fold、epoch、重复计时、失败重试各自是否算独立样本，要按推断目标判断；样本量对应实际推断目标。
- 区分选择集和确认集、主要与探索性分析。确认性分析的指标、排除、停止与多重比较处理在看结果前约定；事后变更注明时间与原因，按事后分析报告。

## 三种结果不要混在一起

| 层次 | 回答的问题 | 不能据此推断 |
| --- | --- | --- |
| 执行状态 | 是否真的运行、结束、产物完整？ | 退出码 0 不等于实现或数据有效 |
| 质量核查 | 数值／数据／评分路径是否符合协议？ | QC 通过不等于研究主张成立 |
| 科学判断 | 在已核对条件下支持、反驳还是仍不可判定？ | 未显著不等于零效果；证据不足不等于证伪 |

失败／中止／未运行保留状态与原因，缺失的指标留空，不填 0；无效测量与有效结果分开存放。有效阴性和不利点照常保留。重试是新的执行尝试：旧失败记录保留，独立重复数不因重试增加。

## 分析时防止过度推断

- 优先报告有意义的效应量、区间／分布与实际观测数，再解释检验。不适用推断统计的确定性比较说明误差来源和测量范围，不强加 p 值。
- “A 显著、B 不显著”不说明 A 与 B 有显著差异，要直接比较差异及其不确定性。证明等效／非劣需要合理界值和对应设计。
- 分清预先指定分析、探索发现和待确认解释；从多指标／多配置里选出的最好结果要说明选择过程。作图时保留选择偏差、失败缺失、分组与配对结构这些信息。
- 消融下降、相关性或单个漂亮案例不能独自证明机制／因果，回看竞争解释、关键对照与适用条件。代理证据外推到整模需要整模验证，外推到其它数据、平台或人群需要各自的证据。
- 结果不足时先定位缺口：执行／QC 问题 → 修复并按授权重跑；对照不可识别 → 调整设计；主张／机制不成立 → 回讨论；证据足够 → 收口。更多同样的运行只解决其中一部分不确定性。

## 图表与记忆交接

- 指明数据、源码／配置、评分协议、派生分析与采用图件的实际版本，用已有 run ID、提交／文件指纹或可信记录即可。
- 图注说明独立单位、重复数和误差条定义；原始值、统计派生和展示舍入分开。需要文献或数据图工具时用 `research-evidence`；图库示例只作画法参考。
- 关键依据变更时，经 `save-mem` 标出受影响的主张／图／稿件与待复核范围，保留旧结论曾成立的条件和历史，按影响范围复核。
